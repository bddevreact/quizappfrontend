# Quizly Logo

This is a placeholder for the Quizly logo. The actual logo.png file should be placed in the public folder.

## Logo Specifications:
- **Format**: PNG with transparency
- **Size**: 512x512 pixels (recommended)
- **Background**: Transparent
- **Style**: Modern, crypto-themed
- **Colors**: 
  - Primary: #00BFFF (Blue)
  - Secondary: #FFD700 (Gold)
  - Accent: #10b981 (Green)

## Logo Design Ideas:
- Q letter with crypto symbols
- Quiz elements (question marks, brain)
- Crypto symbols (Bitcoin, Ethereum)
- Modern gradient design
- Telegram-friendly style

## Usage:
- App icon in browser tabs
- PWA icon
- Social media sharing
- App store listings
- Telegram Mini App icon

## File Location:
```
public/logo.png
```

The logo should be optimized for web use and include various sizes for different platforms.
